# 🎮 Digital Number Guessing Game

A modern **Digital Number Guessing Game** built with **Python** and **Tkinter**. The game features a stylish digital-themed interface with a black-and-green LED-inspired design, guess history tracking, best score tracking, and interactive gameplay.

---

## 📸 Features

* 🎯 Random number generation between **1 and 100**
* 💡 Hints: **Too High** / **Too Low**
* 🏆 Best score tracking
* 📊 Attempt counter
* 📝 Guess history log
* 🎨 Digital-style black & green interface
* ⌨️ Press **Enter** to submit guesses
* 🔄 New Game button
* ❌ Exit button
* 🎉 Congratulations popup on winning
* 🖥️ Centered and fixed-size window
* 🧩 Object-Oriented Programming (OOP) design

---

## 🛠️ Technologies Used

* Python 3.x
* Tkinter (GUI Library)
* Random Module

## 🎮 How to Play

1. Click **START GAME**.
2. Enter a number between **1 and 100**.
3. Click **GUESS** or press **Enter**.
4. Follow the hints:

   * ⬆ TOO HIGH
   * ⬇ TOO LOW
5. Keep guessing until you find the correct number.
6. Try to beat your **Best Score** with fewer attempts.
